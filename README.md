# 🐝 StudyHive

A community platform where students ask questions, share notes, PDFs, past exams, and help each other out.

🔗 **Live App:** [![StudyHive](https://img.shields.io/badge/Open%20App-StudyHive-blue?style=for-the-badge)](https://studyhive-app.onrender.com)

---

## Features

- 📝 Post questions and share study resources
- 🔖 Save posts for later
- 💬 Real-time messaging between students
- 🔔 Notifications for replies and activity
- 🔍 Search posts by tag, course, or keyword
- 👤 User profiles with post history

## Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Socket.io-client  
**Backend:** Node.js, Express, MongoDB, Socket.io  
**Storage:** Cloudinary (file uploads)  
**Auth:** JWT


### Prerequisites
- Node.js v20+
- MongoDB Atlas account
- Cloudinary account

Made with ❤️ for students by student.
